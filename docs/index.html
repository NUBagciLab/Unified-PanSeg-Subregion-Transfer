THE IDEA

Shared anatomy across modalities.

Learn a unified pancreas representation from CT and MRI, then transfer it to the pancreatic head, body, and tail with limited MRI annotations.

The framework combines whole-pancreas segmentation with domain-adversarial learning. A shared 3D nnU-Net encoder learns anatomical features across modalities; the learned encoder then supports downstream subregion segmentation, including transfer to CT without CT subregion training annotations.

01 / DATASET

Pancreas subregion resources

Head, body, and tail segmentation for studying pancreatic anatomy.

RELEASE IN PREPARATION

A dataset built around subregions

This project page will host the pancreas subregion dataset release and its documentation. The public release size, modality breakdown, train/test splits, and access terms will be announced with the dataset.

The model supports T1W MRI, T2W MRI, and CT inference. Model support does not imply that all three modalities will be included in the dataset release.

02 / METHOD

From whole pancreas to its parts

Cross-modality representation learning followed by subregion transfer.

01

Learn anatomy

Train a shared segmentation backbone on heterogeneous CT and MRI scans.

02

Align modalities

Use a domain discriminator and gradient reversal to encourage aligned features.

03

Transfer to subregions

Adapt the learned encoder with limited MRI head, body, and tail annotations.
